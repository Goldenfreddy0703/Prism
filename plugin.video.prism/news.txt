Prism 5.0.65 — Simkl library deadlock (#31)

Fixes ``DeadlockError`` on ``resources.lib.net.sync_bridge`` when opening Simkl library lists (especially My Anime → Watching / On Hold / Dropped) under concurrent plugin threads. The ``net`` package now lazy-loads ``sync_bridge`` and related exports instead of importing them at startup.

Includes all 5.0.64 changes if you skipped that release: library menu window cache, season identity / simklSync schema, anime pack auto-pick (#26), and related sync improvements.
